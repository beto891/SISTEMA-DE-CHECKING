# Sistema de gerênciamento de Checking




## Sobre

_O sistema é composto por 2 ambientes interligados, sendo toda lógica do back-end estruturada através do FLASK, utilizando a linguagem python pra aplicação de lógica de négocio, utilizando também um sistema mobile em Flutter para usuario final da aplicação._

## Funcionalidades (Ambiente Web)

* Importação de campanhas através de arquivo .xlms
* Mapa visual no ambiemte *Web*.
* Tabela para acompanhemento de meta
* Gráfico com porcentagem de entrega por campanha. 
* Acesso restrito a *Admin* e log para úsuario comum.
    * Painel *Admin* para gerenciar e acompanhar entrega (deletar, editar)
* Emissão de relatório em pdf por campanhas.
    * Inclusão de *Pi, dt-inicial e dt-final* na capa.

### App Mobile

1. Visualização por mapa de cada ponto do estabelecimento.
2. Visualização por ponto com lista de campanhas vinculadas no espaço. 
3. Upload de uma ou múltiplas fotos por campanha.
    1. Exemplo de uso (Campanhas por check-in de telas).
